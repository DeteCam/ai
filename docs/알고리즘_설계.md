# DeteCam 6.0 (`Nano-2 AI`) 알고리즘·AI 설계서

## 1. 문제 정의: 왜 고전 신호처리만으로는 소형 2기 수신기가 한계인가?
1. **소형화 딜레마**: 배열을 `84×84 mm`로 줄이면 5 GHz에서는 간격 `20.1 mm < λ/2`가 되어 그레이팅 로브가 사라지지만, 2.45 GHz에서는 `0.16 λ`로 좁아져 소자 간 상호결합 잔류 오차와 실내 다중반사에 취약해집니다.
2. **패널 축소 딜레마 (3기 → 2기)**: 수신기가 2대뿐이면 L자 코너·목욕탕 기둥·화장실 칸막이 뒤(NLoS)나 150석 대형 강당의 얕은 교차각에서 오차가 급증합니다.
3. **전자기기 혼재 딜레마**: 암호화된 Wi-Fi 환경에서는 유튜브 라이브·클라우드 업로드 스마트폰이 몰래카메라와 수동 트래픽 패턴이 거의 동일합니다.

## 2. 4대 Physics-Informed AI 해법

### 2.1 `ReconCovNet-v4` — Differentiable-Capon 물리 잔차 공분산 복원망 (PyTorch)
- **참고 학술 근거**: `SubspaceNet` (IEEE TSP 2025), `ReconUNet` (Sensors 2026), `Neural-MVDR` (JASA 2026)
- **입력**: 보정된 광대역 CSI `H_cal [12, 32]`에서 추출한 제로-바이어스 다중 서브밴드 공분산 3종 `[R_all, R_sub_low, R_sub_high]` (6채널 × 12 × 12) + 대역 플래그(2.45/5.22 GHz). 직선파(LoS)는 상·하부 대역에서 위상이 일치하지만 반사파는 진동하므로 간섭 성분이 즉시 드러남.
- **아키텍처 (457,112 params, `0.024 ms/frame` CPU)**:
  - `R_AI = Norm( W (g_all R_all + g_low R_low + g_high R_high) W^H + g_res L L^H )`
  - 여기서 `W = I + 0.25 tanh(dW)`는 잔류 상호결합 보정, `L (12×3)`은 저랭크 Hermitian PSD 잡음·다중경로 복원 항.
  - 항등 초기화(`R_AI = R_all`) 후 **미분 가능한 2D Capon Soft-Argmin 각도 손실**로 직접 학습 → 100% 미학습 공간(교실·150석 강당·통유리·과밀 기숙사)에서 **2.45 GHz P90 `-16.8%`, 5.22 GHz P90 `-11.1%`** 개선!

### 2.2 `MA-PINN` — Bayesian Log-Sum-Exp 3D 가상 거울 앵커 + `ΔP_12` 전력비 융합
- **핵심 원리**: AR 스캔으로 이미 확보한 3D 방·장애물 지도에서 각 복셀 `q`의 직선 감쇠 `w_dir(q) = cos_front · 10^(-pen_dir/20)`와 1차 경면 반사 이득 `w_mir(q)`를 물리적으로 계산:
  $$\log P_n(q) = \log\!\left(\frac{w_{\text{dir}}(q)\,L_{\text{dir}}(q) + w_{\text{mir}}(q)\,L_{\text{mir}}(q)}{w_{\text{dir}}(q) + w_{\text{mir}}(q)} + \epsilon\right)$$
  - 직선 LoS 복셀에서는 반사 유무로 불이익을 주지 않으면서 일치하는 반사파를 공짜 3·4번째 앵커로 가산.
  - L자 코너·기둥 뒤 NLoS 복셀에서는 `w_dir`이 자동 감쇠하고 `w_mir`가 주도권을 넘겨받아 **거울·벽 반사로 코너 뒤 카메라를 정밀 포착**!
- **`P_tx` 불변 차분 전력비 (`ΔP_12`)**: 2노드 수신 전력비 `10 log10(P_1/P_2)`는 미지의 카메라 송신 전력 `P_tx`가 완벽히 소거되며, `σ = 6.5 dB` 보수적 가우시안 항으로 대형 강당의 2노드 얕은 교차각 깊이 모호성을 추가 하드웨어 없이 해소.

### 2.3 `CamGuard-Net` — 1D-CNN + Multi-Head Self-Attention + 5초 `CamLoPA` 인과 융합
- **아키텍처 (24,482 params, `0.124 ms/device` CPU)**: 15초 암호화 패킷 시계열(업링크·다운링크·전송률·패킷 길이 4채널 × 60빈)을 1D-CNN + 4-Head Self-Attention으로 임베딩하고 5초 조명/손짓 자극 인과 상관계수 `r_causal`·은닉 AP·레거시 1×1 메타 특징과 융합.
- **800대 하드 네거티브 평가**: 수동 분석만 사용 시 `F1 75.64% / 재현율 63.09% / 오경보 3.76%` → **5초 `CamLoPA` 인과 융합 시 `F1 98.88% / 정밀도 98.76% / 재현율 99.00% / 오경보 1.25%`**.

### 2.4 `AR-OPA-2` + `RAPS` Conformal Prediction
- `AR-OPA-2`: 직선 LoS + 1차 가상 거울 반사 가시성 + 3D Fisher Information을 서브모듈러 + 1-Swap으로 0.1초 내 최적화.
- `RAPS`: 분포 무관 Split Conformal Prediction으로 현장 AR 하이라이트 구역의 통계적 `≥ 90%` 포함률 보장.

## 3. 정직한 기술 한계
- Wi-Fi 전파를 일절 송출하지 않는 **오프라인 SD카드 단독 녹화형** 또는 **전원이 꺼진 카메라**는 RF 방식으로 탐지 불가(광학 렌즈 반사/열화상 병행 권고).
- `150석 대형 강당`처럼 14×12 m 초대형 공간에서는 단 2기 기준 P90 `2.06 m`(0원 폰보행 결합 시 `1.04 m`) 수준이며, 초고정밀 1~2석 단위가 필요할 경우 3기 확장 모드 지원.
