# 관련 연구: 몰래카메라를 가려내고 찾는 데 쓴 AI

몰래카메라를 **가려내는 일**(이 기기가 카메라인가)과 **찾는 일**(어디에 있나)에 AI 를 쓴 연구를 모았다. 숫자는 각 논문이 밝힌 것이고, 마지막 칸은 DeteCam 이 무엇을 가져오는지다.

## 가려내기: 이 기기가 카메라인가

| 연구 | 무엇을 보나 | 방법과 결과 | DeteCam 에 |
|---|---|---|---|
| DeWiCam (Cheng 외, AsiaCCS 2018) | 암호화된 Wi-Fi 의 PHY/MAC 머리 (길이, 간격) | 영상 압축이 만드는 트래픽 무늬를 지도 학습. 카메라 20대에서 2.7초 안에 99% | 의심 점수의 특징 (001) |
| CSI:DeSpy (IMWUT 2022) | CSI 로 본 사람의 움직임과 카메라의 비트레이트 변화 | 사람이 움직이면 카메라가 올려 보내는 양이 따라 변하는지를 본다. 가벼운 움직임에서 평균 96.6% | 걷기 확인과 같은 생각. 패널의 CSI 로도 볼 수 있다 |
| Lumos (Sharma 외, USENIX Security 2022) | Wi-Fi 계층의 거친 특징 | 기기 44종을 95% 로 알아보고, 신호 세기와 폰 센서로 가운데값 1.5 m 에 찾는다 (30분). AR 로 보여 준다 | 기기 종류 분류, AR 표시 (app 002) |
| MotionCompass (He 외, MobiSys 2021) | 움직임에 반응하는 트래픽 | 움직임을 일으켜 카메라의 시야를 좁혀 간다. 평균 약 5 cm, 140초 안 | 움직임 감지 카메라를 깨우는 법 |
| SnoopDog (Singh 외, USENIX Security 2021) | 사용자의 움직임과 트래픽의 인과 | 숨은 무선 센서를 찾고 알아보고 위치까지 | 걷기 확인의 바탕 |

## 찾기: 어디에 있나

| 연구 | 무엇으로 | 방법과 결과 | DeteCam 에 |
|---|---|---|---|
| LocCams (Gu 외, IMWUT 2023) | 폰의 CSI | 서브캐리어 분포로 직접 보이는지(LoS)를 가리고 CNN 으로 위치를 낸다. 30초 안에 95.12% | 직접 보이는지 가리기 → 패널마다 믿음 주기 |
| DLoc (Ayyalasomayajula 외, MobiCom 2020) | 여러 AP 의 CSI 를 그림으로 | 심층 신경망이 반사를 익혀 위치를 낸다 | 자리 모델 (002) 의 견줄 대상 |
| del Hougne 외 (Phys. Rev. Lett. 127, 043903, 2021) | 방의 반사와 세기만 | 반사를 부호처럼 쓰고 신경망으로 위치를 낸다 | 세기만 재는 패널과 같은 길 |
| DiffLoc (Zhang 외, USENIX Security 2025), DiffLoc+ (IEEE JSAC 2026) | 라즈베리파이 둘레로 금속판을 돌린 회절 | 평균 방향 오차 14.82° / 11.92° (방 여섯, 카메라 열하나) | 앞선 구조(돌판)의 바탕 |
| CamLoPA (Zhang 외, IEEE S&P 2025) | 사용자가 걷는 길과 회절 | 걷는 길과 신호가 꺼지는 곳으로 위치 | - |
| Wi-Peep (Abedi, Vasisht, MobiCom 2022) | 남의 기기가 돌려주는 응답(ACK) | 빈 프레임을 보내 응답의 시간으로 위치 | 쉬고 있는 카메라 재기 |

## 전파가 아닌 길: Wi-Fi 가 아닌 카메라까지

| 연구 | 무엇으로 | 결과 | DeteCam 에 |
|---|---|---|---|
| ESauron (Zhang 외, USENIX Security 2024) | 카메라 메모리가 내는 전자파 | 장면을 바꿔(번쩍이는 빛) 메모리 전자파가 솟는지 본다. 카메라 50종 모두 자극 네 번에 잡고, 20 m 넘게. 무선·유선·저장만 하는 카메라 모두 | LTE·SD 카메라까지 넓히는 다음 길. 지금 장비는 SDR(USRP)과 로그 주기 안테나 |
| LAPD (Sami 외, SenSys 2021) | 폰의 ToF 센서로 렌즈의 되반사 | 컴퓨터 비전과 학습 거르개. 88.9% (맨눈 46.0%) | 앱의 렌즈 반사 찾기 (나중에) |
| HeatDeCam (Yu 외, CCS 2022) | 열화상과 폰의 작은 신경망 | 95% 넘게. 열화상 22,506장 공개 | 열화상 카메라가 있으면 |
| CamFirm (Liao 외, PerCom 2025) | 값싼 FM 모듈로 전자파 누설 | 가까이 대야 한다 | - |

## 정리

- **가려내기는 AI 가 잘한다.** 영상은 압축 때문에 트래픽에 무늬가 남고, 암호화돼 있어도 길이와 간격은 보인다. 우리는 규칙 점수로 시작해 자료가 모이면 배운 모델로 바꾼다 (001).
- **찾기는 물리가 먼저다.** 방향을 재는 물리 모델이 뼈대이고, AI 는 가려진 카메라의 반사를 익혀 그 위에 얹는다 (002). AI 만으로 찾는 연구는 그 방에서 미리 자료를 모아야 한다.
- **Wi-Fi 가 아닌 카메라**(LTE, SD 카드)는 전파 방향으로는 못 찾는다. 메모리 전자파(ESauron), 렌즈 반사(LAPD), 열(HeatDeCam)이 다음 길이다.
