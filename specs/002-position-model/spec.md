# 002 자리 모델

## 배경

패널은 카메라가 보낼 때마다 안테나 16개의 값을 재고, 허브는 그 값으로 '후보 자리마다의 점수'를 낸다 (물리 모델: 방향 → 자리). 물리 모델은 직접 오는 전파를 가정한다. 사람 몸에 가려 반사로만 보이는 카메라(가슴, 안경)에서 크게 틀린다.

교실 계산에서 물리 모델의 점수에 작은 신경망(은닉층 하나)의 점수를 곱하니 책상 위 +3점, 가슴·안경 +9~10점 올랐다 ([설계 검토 10절](https://github.com/DeteCam/receiver/blob/main/docs/%EC%84%A4%EA%B3%84%20%EA%B2%80%ED%86%A0.md#10-ai-배운-모델)). 배운 모델은 '가려졌을 때 전파가 어느 반사로 오는지'를 그 교실에서 익힌다. 이 스펙은 그 모델을 수신기에 넣을 수 있는 꼴로 만드는 일이다.

## 요구사항

| 번호 | 내용 |
|---|---|
| FR-1 | 입력: 패널마다 후보 점(교실은 자리, 방은 겉면의 점)마다의 물리 점수, 그리고 물리 모델의 자리 확률 |
| FR-2 | 출력: 자리마다의 로그 확률. 물리 모델의 로그 확률에 더해 쓴다 (곱한다) |
| FR-3 | 학습 자료는 그 교실의 치수로 만든 전파 시뮬레이션(사람 배치를 바꿔 가며)이다. 실측 몇 자리로 미세 조정한다 |
| FR-4 | 허브(라즈베리파이 3B+)에서 한 번에 0.1초 안 |
| FR-5 | 교실이 바뀌면 그 교실의 모형으로 자료를 다시 만들고 다시 가르친다 (자료 2분, 학습 몇 분) |
| NFR-1 | 평가는 학습에 쓰지 않은 사람 배치로 한다 |
| NFR-2 | 확률이 지나치게 자신 있지 않아야 한다 (후보 3자리 확률 합과 실제 맞는 비율의 차이 10%p 안) |

## 수용 기준

- 처음 보는 사람 배치 두 가지에서, 물리 모델보다 '정확히 맞힌 비율'이 가슴·안경에서 5%p 이상 높고 책상 위에서 낮지 않다. (계산으로는 +9~10, +3)
- 실물 교실(관문 5)에서 물리 모델보다 나쁘지 않다.
- 둘 가운데 하나라도 못 미치면 모델을 넣지 않고 물리 모델만 쓴다.

## 범위 밖

- 숙소 방은 방마다 모양이 달라 미리 가르치기 어렵다. 방에서는 물리 모델만 쓴다 (방 계산은 물리 모델로 가운데값 0.2~0.26 m).
- 처음부터 끝까지 신경망으로만 자리를 내는 것 (물리 모델 없이). 자료가 적을 때 해롭다 (2,700번으로 가르치면 책상 위 8점 떨어짐).
