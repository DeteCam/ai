# 002 자리 모델 — 계획

## 모델

- 은닉층 하나(256)의 작은 신경망. 입력 = 패널마다 후보 점 점수를 `1 - exp(-s/12)` 로 줄인 것 + 물리 모델의 자리 로그 확률을 자른 것. 출력 = 자리 수만큼의 로그 확률.
- 학습: Adam, 입력 10% 가리기(넘치게 외우지 않게), 가중치 감쇠. 지금 계산 코드는 `receiver/sim/rt/rt_study.py learn` 에 numpy 로 있다. 이것을 PyTorch 로 옮기고 ONNX 로 내보낸다.
- 합치기: `log P = log P_물리 + log P_배운` 을 정규화.

## 자료

1. `receiver/sim/rt/rt_paths.py` 로 그 교실의 사람 배치 8가지 길을 만든다 (GPU 1분씩).
2. `rt_study.py measure` 로 카메라 560대 × 종류 셋을 잰다. 가르치는 것 6가지, 시험 2가지 배치.
3. 실물: 관문 5 의 교실에서 20자리를 재서 미세 조정과 평가에 쓴다.

## 검증

- 시험 배치에서 정확히 / 옆자리까지 / 후보 3자리.
- 확률의 맞음(보정): 후보 3자리 확률 합을 10칸으로 나눠 실제 맞은 비율과 견준다.

## 위험

- 시뮬레이션과 실물이 다르다 → 실측 몇 자리로 미세 조정. 그래도 크게 다르면 넣지 않는다.
- 사람이 많이 움직이는 교실 → 전송을 쌓는 것(6절)과 함께 쓴 결과는 아직 없다. 먼저 계산으로 본다.
