# SPEC-002: 지도 반영 방향 추정과 의심 구역

- 상태: 명세. 회전 수신기 구조로 시뮬레이션만 함, 스위치 고리 구조로는 계산 전. 2026-11-24
- 기준: docs AGENTS.md G2 · G3, 5장(시뮬레이션 규칙), 7.3 · 7.4절
- 수신기: [receiver SPEC-002](https://github.com/DeteCam/receiver/blob/main/specs/002-switch-ring-receiver/spec.md)

## 1. 무엇을, 왜

작은 수신기는 직접 온 전파와 벽 · 천장 반사를 방향으로도 시간으로도 가르기 어렵다. 반사를 지우는 대신 방 크기로 반사 경로를 계산해 함께 맞추면, 반사가 많을수록 기본 방법보다 덜 흔들린다.

## 2. 처리 단계

| 단계 | 내용 | 입력 |
|---|---|---|
| S2 위상 기준 | 패킷마다 (고리 안테나 ÷ 기준 안테나) | 두 단자 CSI |
| S3 간섭 보정 | 대칭 고리 보정표(안테나 하나의 수신 모양을 각도만 돌려 8개에 적용) | 보정표 |
| S4 지도 반영 추정 | 후보 위치마다 직접파 + 벽 · 천장 · 바닥 한 번 · 두 번 반사의 모양을 계산해 맞춤. 경로 세기 · 위상은 측정값에 맞춰 풂(벽 재질을 몰라도 됨). 직접파가 가려진 가설도 함께 계산. 벽 뒤 방향은 제외 | 방 크기, 수신기 위치 · 각도 |
| S5 현장 보정 | 위치를 아는 송신기(폰 · ESP32)를 몇 곳에 두어 수신기 각도 · 위치 · 방 크기를 맞춤 | 송신기 측정 |
| S6 신뢰도 · 구역 | 방향 분포의 퍼짐으로 못 믿을 측정을 거르고, 여러 자리 결과를 합쳐 AR 구역을 만듦 | 가능성 지도 |

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 | 확인 |
|---|---|---|---|
| FR-1 | 방향 정확도 | DiffLoc 재현 장비보다 평균 방향 오차 3° 이상 작고 95% 지점도 작음 | 실측(AGENTS.md 7.3) |
| FR-2 | 반사 견딤 | 반사가 센 방(금속 칠판 · 캐비닛 옆)에서도 FR-1 | 실측 |
| FR-3 | 의심 구역 | 실제 카메라 포함 비율 ≥ 90%, 구역 크기 함께 보고 | 실측(AGENTS.md 7.4) |
| FR-4 | 못 믿을 측정 | 측정 실패 · 거름 횟수를 숨기지 않고 보고 | 실측 |
| NFR-1 | 계산 시간 | 수신기 호스트에서 한 번 계산 5초 이하 | 측정 |

## 4. 지금까지의 근거 (시뮬레이션, 회전 수신기 기준)

docs `기술검증_보고서.md` 2부와 receiver `sim/rt/results/tables.md`:

- 지도 반영 추정은 기본 빔 합성보다 평균 오차를 절반 이하로 줄였다(교실 2.4 GHz 28.5° → 10.2°, 네 모서리 전체).
- 현장 보정은 수신기 각도 6° 오차를 0.6~1.5°로 줄였다(앞쪽 자리). 가려진 자리에서는 듣지 않았다.
- **학습 모델(후보 고르기, 신뢰도, 직접파 판별)은 다른 방에서 시험했을 때 물리 기준보다 낫지 않았다.** 벽별 반사 세기 학습은 오히려 나빠졌다. 다시 시도하면 이 결과와 같은 틀에서 비교한다.
- 이 숫자들은 성능이 아니라 설계 선택의 근거다(AGENTS.md 5.2).

## 5. 범위 밖

카메라 높이를 정밀하게 맞히는 것(수평 고리라 위아래 분해능이 낮음). 교실에서는 앉은 사람 높이 범위를 가정한다.
