# SPEC-002: 지도 반영 방향 추정과 의심 구역 (`SPEC-002+`)

- 상태: 명세 갱신 · 6종 공간 V1 시뮬레이션 검증 완료 · 실측 전 (2026-11-25)
- 기준: [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) G2 · G3, 4장, 5장(시뮬레이션 규칙), 7.3 · 7.4절
- 수신기: [receiver SPEC-002](https://github.com/DeteCam/receiver/blob/main/specs/002-switch-ring-receiver/spec.md) (`SPEC-002+`)

## 1. 무엇을, 왜

지름 8.5~10 cm 손바닥 크기 수신기는 직접 온 전파와 벽 · 천장 · 칠판 · 거울 반사를 방향으로도 20 MHz 시간으로도 가르기 어렵다. 반사를 지우는 대신 방 6면 크기로 반사 경로를 계산해 함께 맞추고, 중심 기준 안테나를 9번째 가상 소자로 통합하며, 2자리(가급적 대각 배치)의 가능성 지도를 신뢰도 가중 결합하여 반사 · 가림 환경에서도 방향 오차를 줄인다.

## 2. 처리 단계 (`SPEC-002+`)

| 단계 | 내용 | 입력 |
|---|---|---|
| S2 위상 기준 · 부호 복원 · 시간 집계 | ① 수동 RF 부호 앵커(`\|α\|≈3.5`, `PE42482` All-Off 50 Ω 보정)로 AX210 패킷당 $\pi$-반전 부호 복원, ② 스윕 패킷에 대해 **$\|H_{\text{ref}}\|^2$ 가중 켤레곱 평균** `sum(H_m · conj(H_ref)) / sum(\|H_ref\|^2)` 적용(V1 대조군에서 비가중 비율 평균 대비 딥 페이드 잡음 폭주 억제 확인), ③ 부반송파별 측정 기준 진폭 `\|H_ref(k)\|` 가중 | 두 단자 CSI (`VesperCSI` + 가드밴드 `±6~10 ms`) |
| S3 9소자 통합 · 간섭 보정 | `dz=0` 중심 기준 안테나(`H_ref/H_ref = 1`)를 9번째 가상 소자로 통합(추가 하드웨어 0원) + 집에서 회전 받침으로 1회 만든 NEC2/실측 보정표(`PE42482` 6 GHz 포트 비대칭 −26.3° 흡수) 적용 | 1회 보정표 |
| S4 방 6면 지도 반영 강건 추정 | **방 6면(1·2차 거울상)** 경로를 계산해 능형 회귀로 맞춤 *(대형 반사체 면 추가는 V1 무제약 회귀에서 이득 없어 선택 · 실험 옵션으로 하향)*. **Huber 부반송파 클리핑 + Student-t 강건 우도**로 미등록 금속 물체(DMC) 이상치를 억제하고, 직접파 가림(NLOS) 가설을 혼합하며 벽 뒤 방향을 제외 | 오차 포함 방 크기, 수신기 위치 · 각도 *(반사체 면은 선택)* |
| S5 현장 보정 | 위치를 아는 송신기(폰 · ESP32)를 몇 곳에 두어 수신기 방향각 · 위치 · 방 크기를 맞춤 | 송신기 측정 |
| S6 신뢰도 · 2위치 의심 구역 | 가능성 지도의 방위각 퍼짐(circular spread)으로 저신뢰도 측정을 표시 · 안내하고, 2자리(1기 2곳 순차 또는 2기 동시, 가급적 대각 배치)의 로그-우도 지도를 **신뢰도 역가중(`1/spread`)으로 비동기 결합**해 AR 의심 구역을 만듦 | 1~2자리 가능성 지도 |

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 | 확인 |
|---|---|---|---|
| FR-1 | 방향 정확도 (G2) | 같은 방(40명 교실 · 금속 칠판 등) · 자리 · 날에 DiffLoc 재현 장비보다 평균 방향 오차 3° 이상 작고 95% 지점도 작음 (2.4 GHz 비교 + 5 GHz 별도 보고) | V1 계산 후 V4 실측 (AGENTS.md 7.3) |
| FR-2 | 반사 · 군중 견딤 | 금속 칠판 · 거울 · 사물함 · 사람 40명 환경에서도 FR-1 충족 (2위치 결합 허용) | V1 6종 공간 계산 후 V4 실측 |
| FR-3 | 의심 구역 (G3) | 실제 카메라 포함 비율 ≥ 90%, 구역 크기 함께 보고 | V6 실측 (AGENTS.md 7.4) |
| FR-4 | 실패 · 저신뢰도 투명 보고 | 802.11b CSI 불가 · 측정 실패 · 저신뢰도 거름 횟수를 숨기지 않고 보고 | V1 · V4 · V6 |
| NFR-1 | 계산 시간 | 수신기 호스트(라즈베리파이 5)에서 1회 방향 추정 5초 이하 | 실측 |

## 4. 사전 검증 근거 (시뮬레이션 — 실측 아님, AGENTS.md 5.4)

- **V1 6종 공간 Sionna RT 2.2 + NEC2 1.3.1 검증 완료** ([`plan_20261125.md`](https://github.com/DeteCam/receiver/blob/main/sim/plan_20261125.md), [`RESULTS_20261125.md`](https://github.com/DeteCam/receiver/blob/main/sim/v1_ring/RESULTS_20261125.md), 모두 **계산값**): 평가 9장면(미학습 `강의실` · `목욕탕` + `worst_metal` 포함)에서 사전 등록 `SPEC-002+`는 2.4 GHz 1자리 `9.7°` / 2자리 대각 `8.2°`(P95 `25.8°`), 5 GHz 1자리 `10.1°` / 2자리 대각 `8.2°`(P95 `30.0°`)를 기록했고, 대조군에서 발견한 사후 후보(`Conj-Avg + 6면 지도`, 분리 표기)는 2.4 GHz `7.6~7.8°`(P95 `23.9~24.4°`), 5 GHz `7.5~7.8°`(P95 `24.8~27.0°`)로 추가 개선되었다.
- **실패 · 효과 없음 기록**: 비가중 비율 평균(`+13.6°` 5G P95), 무제약 대형 반사체 면 추가(`+0.1~0.4°`), 이전 회전 수신기 학습 모델 4종(2026-11-24)은 모두 `docs/알고리즘_설계.md` 3절에 남긴다.
- 위 숫자는 모두 **계산값**이며 설계 선택의 근거로만 쓰고 실측 성능으로 쓰지 않는다.

## 5. 범위 밖

- 카메라 높이를 정밀하게 맞히는 것(수평 고리라 위아래 분해능이 낮음 — 3개 높이 층 탐색 적용).
- 802.11b(DSSS) 폴백 프레임의 CSI 방향 추정(OFDM 부재).
