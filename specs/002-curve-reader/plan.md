# 002 CSI 곡선 판독 모델 — 계획

## 생각

기준선은 '후보 방향 d 에 카메라가 있다면 보였을 곡선 T(d)' 와 잰 곡선 m 을 견주는 함수 s(m, T(d)) 를 사람이 정했다 (틀의 크기를 맞춘 뒤 줄어든 제곱 오차). 이 함수를 **학습한 함수 f(m, T(d))** 로 바꾼다. 모델은 방의 모양을 외울 수 없고(입력에 없다), "반사가 섞이면 곡선이 틀에서 어떻게 벗어나는가"만 배운다. 그래서 다른 방에도 통할 가능성이 높다.

## 데이터 만들기

`receiver/sim/rt` 가 이미 하는 일을 그대로 쓴다: 교실·방 장면에서 광선 추적으로 길을 구하고(Sionna RT), 수신기 무늬 표(NEC2)를 곱해 패킷마다의 CSI 세기를 만든다. 바꿔 가며 뽑는 것: 방 크기와 재질, 사람 수와 자세, 카메라 자리·높이·안테나 방향, 수신기 자리·높이, 패킷 수, 잡음.

- 한 표본 = (스캔 하나의 곡선 [72 × 52], 자세, 후보 방향 하나의 틀 [72 × 2 편파], 그 후보가 참인가)
- 참 후보 1개에 거짓 후보 15개 (가까운 것 위주로 뽑아 어렵게)
- 학습 방 6개, 검증 방 2개, 평가 방 2개 (방 단위로 나눈다)

## 모델

작은 1D CNN 두 갈래 (곡선 갈래, 틀 갈래) → 판 각 방향으로 맞춰 본 특징 → 점수 하나. 파라미터 10만 개 안쪽. 손실은 참 후보가 거짓 후보들보다 점수가 높게 (소프트맥스 교차 엔트로피).

## 실물로 옮기기

1. 조립한 수신기로 트인 곳에서 기준 곡선을 잰다 (receiver 스펙 001 의 교정 절차). 이 곡선으로 무늬 표를 바로잡는다.
2. 바로잡은 표로 데이터를 다시 만들어 학습한다.
3. 실물 스캔 수십 개로 마지막 층만 미세 조정한다.

## 평가

`receiver/sim/rt/rt_eval.py` 에 추정기 하나로 끼워 넣어 기준선과 같은 표로 견준다 (정확히 / 옆자리까지 / 3후보 안). 보정도는 신뢰도 그림으로 본다.

## 위험

- 시뮬레이션과 실물의 차이 → 표를 실물 곡선으로 바로잡는 것이 먼저다. 그래도 차이가 크면 모델 없이 기준선으로 간다.
- 개선 폭이 작을 수 있다 → 수용 기준(5%p)을 못 넘으면 넣지 않는다. 그 경우에도 데이터 생성기와 평가 틀은 남는다.
