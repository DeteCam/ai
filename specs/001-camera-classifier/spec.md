# SPEC-001: 카메라 판별

- 상태: 명세 (실제 데이터 없음). 2026-11-24
- 기준: docs AGENTS.md G1, 7.2절

## 1. 무엇을, 왜

방 안의 여러 Wi-Fi 기기 가운데 카메라를 골라낸다. 패킷 내용은 암호화되어 있으므로 보내는 모양(크기 · 간격 · 양)과, 조명을 끄거나 손을 흔들었을 때 보내는 양이 바로 변하는 반응(CamLoPA 논문과 같은 원리)을 쓴다. 이 결과로 방향을 잴 기기를 고른다.

## 2. 입력과 출력

- 입력: 기기별 패킷 메타 정보 시계열(시각, 크기, 방향, 전송률), 자극 구간 표시, 수신 세기
- 출력: 카메라일 확률, 판정 근거(어떤 특징 때문인지)

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 판별 성능 | 실제 기기 평가에서 재현율 ≥ 95%, 오탐률 ≤ 5% |
| FR-2 | 헷갈리는 기기 | 영상 통화 중인 폰 · 노트북, 라이브 방송, 클라우드 사진 업로드, 홈캠 앱, 스마트 스피커, 로봇청소기를 평가에 포함하고 기기별 결과를 따로 보고 |
| FR-3 | 카메라 종류 | 실시간 영상형과 사진을 간간이 보내는 형을 모두 포함 |
| FR-4 | 평가 방식 | 기기 단위로 나눈 평가(같은 기기는 학습 · 평가 한쪽에만) |
| NFR-1 | 프라이버시 | 패킷 내용을 복호화하지 않음. 원본 캡처와 남의 MAC 주소를 저장소에 올리지 않음 |

## 4. 방법 (계획)

1. 규칙 기준선(업로드 비율, 자극 반응 상관)부터 만든다.
2. 실제 캡처가 모이면 로지스틱 회귀 → 작은 신경망 순으로 비교한다. 각 단계는 앞 단계보다 나을 때만 채택한다.
3. 판정이 애매하면 "의심 기기"로 남기고 방향 측정을 진행한다.

## 5. 범위 밖

전파를 내지 않는 카메라(SD 카드 저장형).
