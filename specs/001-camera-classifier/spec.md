# SPEC-001: 카메라 판별 (수동 802.11 L2/PHY 다중 시간축)

- 상태: 명세 · 공개 실측 데이터(L2 마스킹) LODO 사전 기준선 완료 · AX210 실측 전 (2026-11-26 확인)
- 기준: [docs/AGENTS.md](https://github.com/DeteCam/docs/blob/main/AGENTS.md) G1, 4장, 7.2절 · [ai/AGENTS.md](../../AGENTS.md)

## 1. 무엇을, 왜

방 안의 여러 Wi-Fi 기기 가운데 숨은 2.4 GHz · 5 GHz Wi-Fi 카메라를 골라낸다.
기존 자극 기반 방식(조명 조작 · 사람 움직임 반응, CamLoPA/SnoopDog 원리)은 **시험장(R3 + 조명 고정)에서 사용할 수 없고, MJPEG/고정비트율(CBR) 초소형 카메라(A9/V720 `BK7252`, `ESP32-CAM`)에 반응하지 않으며, 영상통화 오탐(문헌 실측 75%)** 문제가 있다.
따라서 DeteCam은 **수동 802.11 L2/PHY 다중 시간축 분류기**를 기본으로 두고, 자극 반응은 비시험장(숙소 등)에서만 쓰는 선택 보조 증거로 내린다.

## 2. 입력과 출력

- 입력 (복호화 없음, 패킷 메타 정보만):
  - 802.11 MAC 주소 쌍별 패킷 시각 · 프레임 길이 · 방향(SoftAP `FromDS=1`과 STA `ToDS=1`을 모두 잡는 방향 무관 비대칭성)
  - 802.11 PHY/MAC 능력 메타(`rateNflag` 1T1R/2T2R, 20/40/80 MHz, Duration 분포, 802.11b 폴백 여부, LAA 무작위 MAC 보조 비트)
  - 허브 짝짓기(카메라–개인 핫스팟 쌍) · 시험장 입실 전 기준선 대비 신규 등장 여부
  - (선택, 비시험장 전용) 자극 구간 표시
- 출력: 카메라 의심 확률, 판정 근거(어떤 특징 때문인지), 802.11b(DSSS) 폴백 여부

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 판별 성능 (G1) | 실제 기기 AX210 모니터 모드 캡처(2.4 · 5 GHz 각 별도)에서 재현율 ≥ 95%, 오탐률 ≤ 5% |
| FR-2 | 헷갈리는 기기 | 영상 통화 중인 폰 · 노트북, 라이브 방송, 클라우드 사진 업로드, 홈캠 뷰어 앱, 스마트 스피커, 스마트 디스플레이, 로봇청소기를 평가에 포함하고 기기별 결과를 따로 보고 |
| FR-3 | 카메라 종류 | 실시간 영상형과 사진을 간간이 보내는 형(간헐 스냅샷)을 모두 포함하고 두 유형의 재현율을 따로 보고 |
| FR-4 | 평가 방식 | 기기 단위로 나눈 평가(Leave-One-Device-Out; 같은 기기는 학습 · 평가 한쪽에만) |
| FR-5 | SoftAP · 802.11b 대응 | SoftAP(`FromDS=1`) 카메라를 누락하지 않으며, 802.11b 폴백으로 CSI가 없는 기기도 MAC 헤더로 탐지하고 UI에 "CSI 불가" 표시 |
| NFR-1 | 프라이버시 | 패킷 내용을 복호화하지 않음. 원본 캡처(pcap)와 남의 MAC 주소를 저장소에 올리지 않음 |

## 4. 방법과 현재 사전 검증 상태

1. **단계적 비교 원칙 (AGENTS.md 4장)**: `규칙 기준선` → `로지스틱 회귀` → `얕은 GBDT(HistGBDT-Shallow)` → `소형 신경망(MLP)` 순으로 같은 기기 분리 분할에서 비교해 앞 단계보다 나을 때만 채택한다.
2. **공개 실측 데이터(UNSW IoT Traces + Deakin IoT) L2 마스킹 사전 기준선 (`eval/PUBLIC_LODO_RESULTS_20261125.md`)**:
   - L3/L4 헤더를 모두 가린 25개 수동 L2 특징(방향 무관 비대칭성, 프레임 버스트 재구성, 100 ms FFT GOP 주기성, 1초 연속성)으로 완전 기기 분리(LODO) 평가 수행.
   - **발견(실패 기록 포함)**: `SmallMLP`는 기기 분리에서 과적합하여 `LogisticRegression` 및 `HistGBDT-Shallow`보다 열세였다. 7종 카메라 통합 활성 스트림 LODO에서 `HistGBDT-Shallow`가 가장 나았으며(상세 수치는 `eval/PUBLIC_LODO_RESULTS_20261125.md`), **최종 G1(95% / 5%) 달성을 위해서는 V5 AX210 실측에서 6~8종 이상 다양한 카메라 모델 확보 + 802.11 PHY 능력 특징(`rateNflag`, 1T1R/2T2R, 20/80 MHz, 허브 짝짓기) 결합이 필수**임을 확인했다.
3. **판정이 애매하면** "의심 기기"로 남기고 방향 측정을 진행한다.

## 5. 범위 밖 및 알려진 취약 구간

- 범위 밖: 전파를 내지 않는 카메라(SD 카드 저장형).
- 알려진 취약 구간(V5 실측에서 집중 검증): ① 모바일 라이브 방송(암호화 업링크 VBR이 카메라와 유사 → PHY 2T2R/80 MHz 특징으로 분리 검증), ② 간헐 스냅샷 카메라(단일 NIC 채널 호핑 맹점 → 활성 채널 체류 비중 확대, 또는 수신기 호스트에 수신 전용 무선 카드를 하나 더 다는 안을 검토. 지금 설계에는 없으며, 수신기와 따로 두는 기기는 쓰지 않는다, docs AGENTS.md R11).
- 실제 기기 캡처는 아직 없다. 95% 재현율의 아래쪽 신뢰 한계까지 보이려면 카메라 기기 수가 많이 필요하다(예: 59대를 모두 맞혀야 95% 신뢰로 재현율 95% 이상). 모을 수 있는 기기 수에 맞춰 보고 방식을 정한다.
